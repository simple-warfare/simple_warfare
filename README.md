# SimpleWarfare
SimpleWarfare is a real-time strategy game. Set in the distant future where mega corporation battle themselves this standalone title comes with multiplayer (LAN and internet) support, competent skirmish bots as well as an integrated map editor. It allows for spectators to join and replays to be shared.
# Mod support
What's important,it supports to use 
`ECMAScript` and `Lua` to create your own mod.
